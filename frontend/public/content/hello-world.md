# Hello, World

Welcome to the viz-vibes blog. This is where I'll share thoughts on music, code, and creative experiments.

## Why viz-vibes?

I built viz-vibes as a creative experiment — a place where AI-generated music meets interactive WebGL visualizations. The idea was simple: what if listening to music could be more visual, more playful?

## The stack

- **Frontend**: Next.js + React, with custom WebGL shaders for the visualizer
- **Audio**: Web Audio API for real-time frequency analysis
- **Backend**: FastAPI serving tracks from Cloudflare R2
- **3D**: Three.js for the floating interactive figures

## What's next

More music, more visuals, more experiments. Stay tuned.
